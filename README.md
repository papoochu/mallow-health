# Mallow 🌿

Mallow is a personal health dashboard and intelligent health companion for tracking medical and wellness data from Apple Health, Apple Watch, and connected devices.

Planned features include:

- Heart rate and HRV trends
- Blood pressure tracking
- Blood glucose and CGM data
- Respiratory rate and blood oxygen
- Temperature trends
- Sleep analysis
- ECG and rhythm data
- Personal baseline monitoring
- Anomaly detection
- AI-assisted health insights and explanations

> Mallow is a personal project and is not intended for diagnosis, treatment, or clinical use.
